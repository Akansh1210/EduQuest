# EduQuest 🎓

**Learn. Explore. Play. Grow.**

EduQuest is a beginner-friendly, mobile-first educational web application concept for students in Classes 6–10. It makes learning more engaging through subject cards, short quizzes, instant feedback and points.

## Current features (Version 1)
- Responsive homepage for mobile and desktop
- Class selector (Classes 6–10)
- English, Mathematics, Science and Social Science quiz samples
- Instant answer feedback and explanations
- Points and completed-quiz counter
- Progress saved in the browser using `localStorage`

## Run locally
1. Download or clone this repository.
2. Open the `EduQuest` folder.
3. Open `index.html` in a browser.

For the best development experience, open the folder in Visual Studio Code and use the Live Server extension.
